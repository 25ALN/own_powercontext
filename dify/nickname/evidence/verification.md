## 3. 补充完整验收的最小步骤

在 `nickname/` 目录执行：

```bash
python3 scripts/init_demo.py --empty
```

脚本自动创建唯一名称的 Scope，不预置故事。将输出的 `PC_SCOPE_A` 填入 Dify，确认读写均绑定该变量，关闭 LLM 内置会话记忆。

1. 新建对话 A，输入“我把周报文件命名为‘周报_海盐柠檬’，结果发错了群。”保存首次读取的空 `hits`、本轮实际回复、写入状态码和非空 `records`，包含记录 ID 与正文。
2. 新建对话 B，保持 Scope 不变，输入“今天开会又忘记共享屏幕了。”保存搜索原始输出，确认命中的正文包含对话 A 生成的称号及经历，再保存实际回复与本轮写入结果。
3. 原始输出保存为 `01-write.json`、`02-recall.json`，补充能区分两个会话的截图。记录实际 Scope ID 和两次会话 ID，保留记录对应关系，隐藏令牌。

确认标准：首次检索为空；首轮实际生成内容写入成功；第二轮新会话检索到同一条记录；回复使用该记录；第二轮也保存成功。
