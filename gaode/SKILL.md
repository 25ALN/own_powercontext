# 周边去哪儿

## 用途与适用场景

当用户询问起点附近的咖啡馆、餐厅、公园或其他地点，并希望知道步行距离或时间时使用本 Skill。输入通常包含城市、起点名称、起点经纬度和自然语言偏好。评测环境会提供起点坐标；直接使用给定坐标，不要用 IP 定位或自行猜测位置。

## 执行流程

1. 从需求中提取地点类别或关键词、步行时间上限、最多推荐数量、排序偏好及其他明确筛选条件。默认最多推荐 3 个；用户明确要求更少时遵从用户数量。不要把未提及的偏好当作筛选条件。
2. 使用工具前先确认当前工具目录中有高德周边搜索和步行路线工具，并遵循它们实际提供的参数 Schema；若必需工具不存在，不要假装查询成功。使用高德 `maps_around_search` 搜索周边 POI：`keywords` 填需求类别或关键词，`location` 填起点坐标，格式为 `经度,纬度`，`radius` 是搜索半径（米，可选）。如 Schema 提供 `region`，可传入用户给出的城市；不要把起点地址拼进坐标字段。坐标原样使用，不要交换经纬度或自行转换坐标系。
3. 首次周边搜索使用 `radius=2000` 米。根据结果中的名称、类型、地址剔除明显不符合需求或重复的 POI。若路线验证后符合条件的地点少于用户要求数量，再扩大到 `radius=5000` 米搜索一次；合并并去重两次结果，勿无限扩大范围或反复搜索。回答中说明实际搜索范围。若搜索工具不接受该参数或单位，以工具 Schema 为准并采用其可用的最大限度明确范围。
4. 使用搜索结果中的 POI ID、名称、地址和坐标。若缺少路线所需的坐标且有 POI ID，调用 `maps_search_detail` 并以该 POI ID 填 `id` 补查；仍无坐标或身份信息不足时，不为其编造路线或推荐。对当前搜索结果中每个可确认、符合类别要求且去重后的候选，分别调用 `maps_direction_walking` 查询路线，`origin` 为给定起点坐标，`destination` 为该 POI 坐标，格式均为 `经度,纬度`。只有工具 Schema 支持时才附带起点或终点 POI ID。各地点都是从同一起点出发的独立备选，不要串成多站行程。
5. 必须从步行规划结果读取路线距离和耗时；不使用周边搜索距离、直线距离、距离换算速度或其他出行模式代替。高德步行路径 `duration` 按秒解释；若用户给出分钟上限，先乘以 60 再与未舍入的原始秒数比较，保留 `duration <= 上限秒数` 的路线，例如 15 分钟对应 900 秒。不要先四舍五入再判断。展示时将秒换算为易读分钟；距离使用路线返回值及其单位，不自行估算。若工具返回多个方案，选择耗时最短且满足用户时间上限的方案；没有时间上限时使用工具标示的首选方案。若返回结构未提供可识别的路线距离或耗时，先依据工具说明确认字段含义和单位；仍无法确认时，不将该地点列作已验证推荐。不得将超时地点混入符合条件的推荐。
6. 按用户偏好排序。“优先近一点”按已选步行路线的距离从短到长排序；距离相同或没有明确距离偏好时，可用路线耗时作为次要排序依据。不要按搜索半径内的 POI 直线距离冒充步行距离。其他偏好只在搜索结果或工具数据能够支持时用于筛选或排序。最多返回用户要求的数量，且不超过 3 个。
7. 每条推荐的名称、地址、距离、耗时和理由都必须能由高德返回数据支持。理由说明地点类型为何符合需求，或路线数据为何符合用户的距离/时间偏好；不要臆测环境、口碑、安静程度、排队、营业状态或服务质量。数据没有提供或无法确认的属性明确标注“未核实”，不要将其写成事实。

## 回答格式

用简短列表或表格回答。每个地点包含：

- **名称**及**地址**（使用高德返回内容）
- **步行距离**与**预计步行时间**（使用该地点步行路线的返回值）
- **推荐理由**（每个地点一句话，只写有数据依据的类别匹配或步行路线优势）

简要说明地点从用户起点独立出发。只有查询结果支持时才说明结果数量、排序依据或具体筛选情况。

## 结果不足与异常

- 符合条件的地点少于用户要求数量时，只列出实际符合条件的地点，并说明本次查询范围或路线结果中符合条件的地点不足；不要用不符合时间上限的结果凑数。可建议用户放宽时间、类别或范围。
- 搜索成功但没有合适地点时，如实说明没有找到符合条件的结果。不要虚构 POI、地址、坐标或路线。
- 某候选地点缺少坐标、详情或有效步行路线时，跳过该地点；若因此影响结果数量，简要说明哪些信息未能核实。
- 工具调用失败时，不要把失败说成“没有结果”，也不要编造成功数据。说明失败的是周边搜索、地点详情还是步行路线；若仍有已经成功验证且符合条件的结果，可只推荐这些结果，并说明查询受限。若无法验证任何结果，明确告知暂时无法完成查询，并请用户稍后重试或放宽条件。
